# Автоматический краткий пересказ

Сервис помогает контент-менеджеру быстро готовить краткие пересказы статей для анонсов,
дайджестов и рассылок. Контент-менеджер отправляет текст, а сервис возвращает краткий пересказ
с сохранением основных идей и высказанных в тексте тезисов.

## Основные пользователи

Основной пользователь — контент-менеджер новостного или медиа-проекта.
В работу контент-менеджера входит подготовка коротких текстов к статьям: анонсов, подводок и подборок для рассылок.
Сейчас для этого нужно прочитать материал и написать его краткую версию вручную.

Такой выбор соответствует [ML-модели](../ml/model-card.md) проекта: она обучена на новостях,
поэтому новостные тексты для неё наиболее привычны.

Далее в документации слово «пользователь» означает контент-менеджера.

## Бизнес-ценность

Сервис заменяет написание пересказа с нуля проверкой готового черновика:

- контент-менеджер тратит меньше времени на рутинную работу и больше на проверку и редактуру;
- редакция может выпускать больше анонсов и рассылок без расширения команды.

Ценность сервиса можно измерять двумя показателями:

- среднее время подготовки одного анонса;
- доля пересказов, принятых без доработки.

## Основные функции

- приём текста и файлов для пересказа;
- суммаризация текста;
- отображение статуса обработки;
- просмотр и копирование результата;
- доработка пересказа по замечаниям.
