# Автоматический краткий пересказ

Сервис позволяет пользователю отправить текст для анализа. 
На выходе пользователю предоставляется краткий пересказ отправленного текста, 
с сохраниением основных идей и высказанных в тексте тезисов.

Основные пользователи:
- пользователь, отправляющий текст;

Основные функции:
- прием текта для пересказа;
- процесс сумаризации;
- просмотр результата суммаризации пользователем;
