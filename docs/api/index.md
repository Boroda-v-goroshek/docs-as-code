# API

API предоставляет доступ к функциям сервиса автоматического краткого пересказа.

Пересказ выполняется асинхронно: запрос сначала попадает в очередь задач,
а статус и результат клиент получает отдельным запросом.

## Основные операции

- `POST /summaries` — отправить текст на пересказ;
- `GET /summaries/{id}` — получить статус обработки и результат;
- `POST /summaries/{id}/revisions` — переделать пересказ по замечаниям пользователя.

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).
